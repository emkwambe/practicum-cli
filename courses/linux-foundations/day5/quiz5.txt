Q1: set -e at the top of a bash script does what?
A) Sets the default editor
B) Enables echo mode
C) Stops the script immediately if any command fails — prevents cascading errors
D) Sets environment variables
Correct: C

Q2: SCENARIO: Your boss asks "how many errors did we have yesterday?" The log file is app.log. Which pipeline gives the count?
A) count ERROR app.log
B) grep "ERROR" app.log | wc -l
C) find ERROR app.log
D) cat app.log | count ERROR
Correct: B

Q3: df -h shows:
A) Directory files in human format
B) Running processes
C) Disk free space in human-readable format (how full each partition is)
D) Downloaded files
Correct: C

Q4: SCENARIO: You wrote a script called deploy.sh. When you run ./deploy.sh it says "Permission denied". The fix is:
A) chmod +x deploy.sh — then ./deploy.sh works
B) Delete and recreate the file
C) Run it as root
D) Rename the file
Correct: A

Q5: A well-written script should return exit code 0 on success and what on failure?
A) 0
B) -1
C) A non-zero code (typically 1)
D) Nothing — exit codes are optional
Correct: C
