Q1: You just SSH'd into a server you've never used before. What's the first command to orient yourself?
A) ls -la
B) whoami
C) pwd — it tells you exactly where you are in the filesystem
D) cd
Correct: C

Q2: Which command lists ALL files, including hidden ones like .bashrc?
A) ls
B) ls -a
C) ls -l
D) list --all
Correct: B

Q3: You're in /home/user/projects/app/src. You need to go up to /home/user/projects. How?
A) cd /projects
B) cd home
C) cd back
D) cd ../..
Correct: D

Q4: mkdir -p logs/2026/may creates:
A) Only the folder "may"
B) Only "logs" and fails on the rest
C) All three nested folders (logs, 2026, may) even if none exist
D) A file called logs/2026/may
Correct: C

Q5: You run touch on a file that already exists. What happens?
A) The file is deleted
B) The file contents are erased
C) An error occurs
D) The file's timestamp is updated — contents are untouched
Correct: D
