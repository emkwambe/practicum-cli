Get Started

Install in 60 seconds.

Runs on any machine with bash. No root. No Docker. No VM. Just your terminal.

🐧 Linux / WSL

Ubuntu, Debian, Fedora, Arch

One command:

curl -sL
https://practicum-cli.dev/install.sh | bash

Or clone manually:

git clone https://github.com/emkwambe/practicum-cli.git
cd practicum-cli && chmod +x practicum
./practicum start

💻 Windows

Windows 10 / 11

Open PowerShell as Admin, run wsl --install, restart. Open "Ubuntu" from Start menu. Then:

curl -sL
https://practicum-cli.dev/install.sh | bash

🍎 macOS

Intel & Apple Silicon

Open Terminal.app or iTerm2:

curl -sL
https://practicum-cli.dev/install.sh | bash

Works on both bash and zsh.
